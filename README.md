
# iyf-s12-week-07-justinpk561-cyber

## Week 7: JavaScript Best Practices

A refactored To-Do List application built with HTML, CSS and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete individual tasks
- Filter tasks (All, Active, Completed)
- Clear completed tasks
- Save tasks using localStorage
- Remember filter preferences
- Modular JavaScript structure

## Technologies

- HTML5
- CSS3
- JavaScript ES Modules
- localStorage
- ESLint
- Prettier
- Vitest

## Project Structure

- `index.html` - Application structure
- `styles.css` - Application styling
- `js/` - JavaScript modules
- `tests/` - Unit tests
- `cart/` - Shopping cart project
- `daily-challenges/` - Daily JavaScript challenges

## Installation

Requires Node.js 22 or 24.

```bash
npm install
npm run lint
npm test
```
